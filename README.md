# Лабораторная работа №1 — вариант 8

**Вариант:** `RGB ↔ XYZ ↔ HSV`.

Приложение сделано как статический веб-сайт на HTML + CSS + JavaScript и готово для GitHub Pages.

## Что реализовано

- Строгая цепочка варианта 8: **RGB ↔ XYZ ↔ HSV**.
- Нет прямого преобразования RGB ↔ HSV: при таком пересчёте используются промежуточные XYZ по цепочке задания.
- Все расчёты написаны вручную на JavaScript, без библиотек конвертации цветов.
- RGB ↔ XYZ с sRGB-гамма-коррекцией из методических формул.
- HSV рассчитан по алгоритму из предоставленной блок-схемы: максимальная компонента, насыщенность, шесть секторов оттенка.
- Выбор стандарта освещения **D65 / D50 / E**.
- Матрица RGB → XYZ и обратная матрица пересчитываются программно при смене освещения.
- Для XYZ → RGB есть **Clipping** и **Scaling** при выходе за RGB-гамут.
- Три способа задания цвета: точные поля, ползунки и большая палитра / native color picker.
- Динамический большой предпросмотр цвета.
- Автоматический пересчёт всех трёх моделей после изменения любой компоненты.
- Ненавязчивое предупреждение о выходе за границы RGB.
- Разделение на Model / View / Controller.
- Автоматические микро-тесты без внешних библиотек.

## Запуск локально

Для проверки можно открыть `index.html` через любой современный браузер. Если браузер блокирует ES-модули при открытии через `file://`, запустите простой статический сервер.

Например, в VS Code удобно использовать Live Server.

## GitHub Pages

1. Создайте репозиторий.
2. Загрузите **все содержимое этой папки** в корень репозитория.
3. В GitHub откройте `Settings → Pages`.
4. В качестве источника выберите ветку с файлами, например `main`, и папку `/ (root)`.
5. Сохраните настройки и откройте выданный адрес Pages.
