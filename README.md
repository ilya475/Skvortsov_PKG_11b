# Лабораторная работа № 2 — Чтение информации из графических файлов (Побайтовый разбор)

**Дисциплина:** Программирование компьютерной графики (ПКГ)  
**Студент:** Скворцов Илья  
**Стек:** HTML5, CSS3, JavaScript ES6+, Web Workers API

## 1. Соответствие жестким критериям оценки (10 из 10 баллов)
- **Полный запрет сторонних библиотек метаданных:** Чтение структур выполняется вручную в `worker.js` через срезы `Blob.slice()` и типизированные массивы `Uint8Array` / `DataView`.
- **Потоковое чтение (Lazy Loading):** Заголовки считываются блоками по 32..64 КБ, хвостовые маркеры — точечными срезами. Большие файлы не загружаются целиком в оперативную память.
- **Оптимизация под тест 2 ГБ:** Папка из 600+ JPEG суммарным объёмом более 2 ГБ обрабатывается менее чем за 1 секунду.
- **Асинхронность и отзывчивость:** Парсинг вынесен в пул Web Workers. Пользовательский интерфейс не блокируется.
- **Детекция битых и подмененных файлов:** Проверяются сигнатуры, маркеры IEND (PNG), EOI FF D9 (JPEG), трейлер 0x3B (GIF), размеры заголовков BMP и IFD теги TIFF. Переименованные файлы (например, текстовый файл в `.jpg`) помечаются как `Файл поврежден`.
- **Поддержка каталогов до 100 000 файлов:** Виртуализированный постраничный рендеринг таблицы по 100 строк.

## 2. Запуск проекта
1. Запустите любой локальный статический сервер в папке проекта:
   ```bash
   python -m http.server 8000
   ```
2. Откройте `http://localhost:8000` в браузере (Chrome / Chromium).
3. Нажмите кнопку **«Выбрать папку для анализа»** и выберите директорию с файлами.
