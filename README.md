# RasterLab — лабораторная работа №4

## Запуск
1. Распаковать архив в любую папку.
2. Открыть `index.html` в современном браузере (Chrome, Edge, Firefox).
3. Для построения выбрать алгоритм, задать координаты и нажать «Построить».
4. Для замеров открыть раздел Benchmark и нажать «Запустить тест».

Интернет и установка библиотек не требуются.

## Состав
- `index.html` — структура веб-интерфейса.
- `style.css` — оформление и адаптивная компоновка.
- `app.js` — виртуальный растр, алгоритмы, визуализация и бенчмарк.
- `Отчет_Лабораторная_работа_4.docx` — сопроводительный отчёт.

## Архитектура
Алгоритмы получают координаты и ссылку на целевой массив, в который записывают интенсивность пикселя. Они не вызывают графические примитивы. Canvas читает массив и отображает ячейки, оси и сетку. Время основного теста включает только алгоритмическую запись в `Float32Array`, без UI-отрисовки.

## Примечание
Точные миллисекунды зависят от оборудования и браузера. Запустите Benchmark на компьютере, где будет демонстрироваться работа, и перенесите фактические значения из таблицы интерфейса в отчёт при необходимости.
