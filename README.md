## Публикация на GitHub Pages

**Важно:** GitHub Pages не публикует ZIP автоматически. Сначала распакуйте архив и загрузите отдельные файлы.

1. Создайте публичный репозиторий GitHub.
2. Нажмите **Add file → Upload files**.
3. Загрузите в корень репозитория `index.html`, `style.css`, `app.js`, `report.html`, `README.md` и DOCX-отчёт. Не помещайте их во вложенную папку.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. Выберите **Deploy from a branch**, ветку `main`, папку `/(root)` и нажмите **Save**.
7. Дождитесь публикации и откройте ссылку, показанную в разделе Pages.

Если файлы не загружаются, не загружайте сам ZIP; распакуйте его и загрузите файлы по отдельности. Если загрузка браузером не срабатывает, попробуйте выбрать файлы через кнопку Upload files или использовать GitHub Desktop.

## Состав проекта

- `Лабораторная_работа_4_Скворцов_Илья.docx` — отчёт Word.

## Проверка перед сдачей

Проверьте отрезки с разными наклонами и направлениями, окружность и эллипс. Запустите стресс-тест: 1 000–100 000 отрезков, серии по 5 000 отрезков различной длины и 50 000 окружностей. Сохраните CSV и используйте реальные значения в окончательных выводах: результаты зависят от устройства и браузера.

**Замечание о критерии 9–10 баллов.** В проекте реализован целочисленный алгоритм средней точки для эллипса. В листе задания отдельно назван алгоритм Кастла—Питвея, но его формулы в приложенном задании отсутствуют. Поэтому перед сдачей необходимо сверить именно эту формулу с материалами преподавателя; текущая реализация не выдаётся за подтверждённую реализацию Кастла—Питвея.
