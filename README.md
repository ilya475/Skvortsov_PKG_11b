**Тема:** Чтение информации из графических файлов

## Запуск
Откройте `index.html` в современном браузере через локальный HTTP-сервер либо разместите четыре основных файла (`index.html`, `style.css`, `app.js`, `worker.js`) в корне GitHub-репозитория и включите GitHub Pages. Для корректной работы Web Workers предпочтителен HTTP(S), а не открытие файла двойным щелчком.

## Возможности
- анализ JPEG/JPG, GIF, TIFF/TIF, BMP, PNG и PCX;
- ручное чтение бинарных полей без сторонних библиотек метаданных;
- определение формата по сигнатуре, а не по расширению;
- выбор папки или отдельных файлов;
- параллельный разбор в Web Workers;
- чтение только необходимых диапазонов через `Blob.slice()`;
- проверка обязательных структур и границ файла;
- поиск, фильтры, постраничный вывод по 100 строк;
- экспорт результатов в CSV и просмотр изображения.

## Архитектура
- `index.html`, `style.css` — интерфейс;
- `app.js` — очередь, пул рабочих потоков, прогресс, фильтры и экспорт;
- `worker.js` — ручные парсеры форматов.

## Расчёт DPI при отсутствии метаданных
Сначала приложение пытается извлечь физическое разрешение из полей формата (JFIF/EXIF, pHYs, X/Y pixels per meter, HDPI/VDPI или TIFF-теги). Если эти данные отсутствуют, в таблице показывается **«не задано»**, а в графе **«Физ. размеры, см»** появляются поля **Ш** (ширина) и **В** (высота). Пользователь вводит реальные физические размеры изображения в сантиметрах (можно использовать десятичную запятую или точку). Когда обе величины положительны, DPI рассчитывается автоматически по двум осям:

- `DPI_X = ширина_в_пикселях × 2,54 / ширина_в_сантиметрах`;
- `DPI_Y = высота_в_пикселях × 2,54 / высота_в_сантиметрах`.

Пример: изображение 1900 × 1200 px при физических размерах 15,24 × 10,16 см даёт около **316,67 × 300 dpi**. Значение отдельно помечается как «расчёт по размерам пользователя» и не считается метаданными файла. Если DPI корректно указан в метаданных, используются именно они, ручной ввод не требуется. Результат и введённые размеры попадают в CSV. При изменении размеров DPI пересчитывается сразу; при фильтрации/переключении страниц значения остаются до очистки результатов или новой загрузки.
