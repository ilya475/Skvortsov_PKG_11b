# Лабораторная работа №3 — «Основы обработки цифровых изображений»

**Выполнил:** Скворцов Илья, **группа 11**. 2026 год.

Готовый проект для GitHub Pages: интерактивный стенд, 32 алгоритма обработки изображений, 10 тестовых PNG, цветные карты градиента, гистограммы и измерения, 1/2/4 фоновых рабочих потока, 15-страничный PDF-отчёт и HTML-версия отчёта. Все функции обработки находятся в `src/algorithms.js` и реализованы вручную на JavaScript через типизированные массивы; нет серверной обработки, OpenCV или зависимостей от CDN.

## Как опубликовать на GitHub Pages

1. **Распакуйте ZIP.** Откройте папку `lab3-skvorcov-ilya` и загрузите **её содержимое** в корень нового публичного репозитория GitHub. В корне должны лежать именно `index.html`, `report.html`, `styles.css`, `src/`, `assets/` и `report/`. Не помещайте весь проект в дополнительную вложенную папку, если публикация настроена из корня репозитория.
2. На GitHub откройте репозиторий → **Settings → Pages**.
3. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
4. Откройте адрес вида `https://<username>.github.io/<repository>/`. Главная страница — веб-приложение; отчёт открывается по пункту меню **«Отчёт»**, а PDF — по **«PDF-версия»**.
5. Для демонстрации преподавателю загрузите тестовый пример внизу страницы, выберите метод и параметры, нажмите **«Обработать изображение»**. Рядом появятся обработанный кадр, числовые показатели и две гистограммы.

**Важно:** двойной щелчок по `index.html` (`file://`) может не запустить ES-модули и Web Workers из-за ограничений безопасности браузера. Используйте опубликованную HTTPS-страницу или локальный HTTP-сервер. Никакой сервер не нужен после публикации — GitHub Pages раздаёт статические файлы.

## Локальный запуск

Из корня проекта (для проверки без GitHub):

```bash
python -m http.server 8000
```

В браузере откройте `http://localhost:8000/`. Подойдут современные Chromium, Edge и Firefox, поддерживающие ES modules, Canvas и Web Workers. Зависимости `npm install` не требуются.

## Что реализовано

- **Поэлементные операции (4):** негатив, яркость, гамма, линейное контрастирование.
- **Низкочастотная фильтрация (2):** бокс-фильтр и гауссово сглаживание, оба через две одномерные свёртки.
- **Высокочастотная фильтрация (2):** лапласиан и Unsharp Mask.
- **Сегментация (4):** обнаружение точек, Собель с картой направлений, Кэнни с интерполированным подавлением немаксимумов и субпиксельной оценкой, прямые Хафа.
- **Порядковые нелинейные фильтры (4):** медиана, минимум, максимум, произвольный процентиль.
- **Контраст и гистограммы (3):** RGB-эквализация, HSV/V-эквализация, CLAHE.
- **Пороговая обработка (6):** Оцу, межсредний порог, ручной контрольный порог, Брэдли, Саувола, Ниблэк.
- **Морфология (7):** эрозия, дилатация, открытие, закрытие, морфологический градиент, Top-Hat, Black-Hat. Структурирующие элементы: диск, квадрат, ромб, крест.

Итого: **32 алгоритма**. Методика задаёт две группы методов по номеру в списке (варианты 1–20). Поскольку предоставлен **номер группы 11**, но не порядковый номер студента в списке, поддерживаются **все варианты таблицы без исключений**. Дополнения к заданию применены независимо от ошибочной подписи «10А».

## Архитектура

```text
lab3-skvorcov-ilya/
├── index.html                      # Стенд; стартовая страница Pages
├── report.html                     # Полный HTML-отчёт
├── report.css, styles.css          # Адаптивная и печатная стилизация
├── src/
│   ├── pixel-buffer.js            # RGBA, Clamp / Reflect, операции чтения
│   ├── algorithms.js              # Чистые математические алгоритмы
│   ├── config.js                  # Описание 32 методов и параметров
│   ├── app.js                     # UI, тестовые наборы и графики
│   ├── parallel.js                # Фоновая обработка, деление на полосы
│   └── processing.worker.js       # Отдельный Web Worker
├── assets/tests/                  # 10 тестовых PNG
├── assets/reference/              # Эталонная маска и «чистые» кадры
├── tests/algorithms.test.mjs      # Проверки Node.js
├── report/
│   ├── Отчет_Скворцов_Илья_ЛР3.pdf
│   ├── Отчет_Скворцов_ЛР3.md      # Исходный текст отчёта
│   ├── experiments.json           # Численные результаты JS-модулей
│   ├── browser_qa.json            # Время и побайтовая проверка Web Workers
│   └── figures/                  # Графики и изображения экспериментов
├── docs/Методические_указания_ЛР3.pdf
├── tools/                          # Воспроизведение испытаний и отчёта
└── package.json
```

**Два режима границ:** Reflect-101 и Clamp. **Оптимизации:** разделяемые свёртки O(K·WH), интегральные изображения O(WH) для локальной статистики, 2–4 параллельных Web Workers для Gaussian/Box с перекрытием полос. **Качество:** независимые гистограммы «до / после» в одной вертикальной шкале, статистические показатели, F1 и PSNR в отчёте.

## Проверка и воспроизводимость результатов

При установленном Node.js 20+ (проверено на Node.js 22):

```bash
npm test
```

Тесты проверяют все 32 алгоритма, сходимость Otsu, суммирующие таблицы, постоянное изображение после свёртки, совпадение полос, преобразования цвета, морфологические операции, карту углов и альфа-канал. Проверки не требуют внешних пакетов.

Для воспроизведения созданных изображений и экспериментальных таблиц нужны Python 3 и только внешние пакеты **Pillow**, **NumPy**, **Matplotlib**, **mistune**, **BeautifulSoup4**, **WeasyPrint** (они используются *только в инструментах разработки*, а **не** веб-приложением). Последовательность:

```bash
python tools/generate_samples.py
python tools/experiment_pipeline.py
python tools/build_report.py
```

`tools/compute_experiments.mjs` запускается из конвейера и вычисляет все сравнения средствами тех же JS-функций, что и браузер. `tools/browser_bundle_qa.py` предназначен только для изолированного QA в управляемом Chromium и не участвует в работе Pages. Истинный браузерный запуск строится через обычные `import` и `Worker(new URL(...), {type: 'module'})`.

## Как повторить ключевые эксперименты в интерфейсе

1. **Контраст:** «Низкий контраст» → «Линейное контрастирование» (1%) → «HSV» → «CLAHE» (тайл 64, clip 2); сравните диапазон P5–P95, энтропию и гистограммы.
2. **Адаптивный порог:** «Неровная освещённость» → «Оцу» → «Брэдли» (радиус 15, k=0,15) → «Саувола» (радиус 15, k=0,20); сопоставьте внешний вид с F1 в PDF.
3. **Импульсный шум:** «Импульсный шум» → «Бокс 5×5» → «Медиана 3×3»; количественные PSNR доступны в отчёте.
4. **Сегментация:** «Линии и точки» → «Собель», «Кэнни» или «Хаф», рассмотрите карту направления градиента.
5. **Морфология:** «Мелкие структуры» → «Top-Hat» / «Black-Hat» / «Морфологический градиент», меняйте форму и радиус структурирующего элемента.
6. **Многопоточность:** «Большой кадр» → «Гауссов фильтр» → выберите 1 или 4 Web Workers, сравните измеренное время.
