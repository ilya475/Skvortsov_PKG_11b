# Лабораторная работа № 2 — чтение информации из графических файлов

**Дисциплина:** ПКГ  
**Студент:** Скворцов Илья  
**Реализация:** веб-приложение на HTML, CSS и JavaScript

## Цель

Закрепить знания о структуре растровых форматов и научиться извлекать метаданные непосредственно из байтов графического файла. Приложение показывает размеры изображения, разрешение, глубину цвета, способ сжатия и статус проверки файла.

## Возможности

- Анализ JPEG/JPG, GIF, TIFF/TIF, BMP, PNG и PCX.
- Определение формата по сигнатуре содержимого, а не только по расширению.
- Ручной побайтовый разбор без сторонних библиотек метаданных.
- Выбор папки, очередь обработки и ограниченное число Web Workers.
- Чтение необходимых диапазонов через `Blob.slice()` вместо загрузки каждого файла целиком.
- Прогресс-бар, счётчики, поиск, фильтры по формату и статусу.
- Постраничная таблица по 100 записей и экспорт CSV.
- Обработка ошибок разбора с пояснением в результатах.

## Архитектура

| Слой | Файл | Ответственность |
|---|---|---|
| Presentation | `index.html`, `style.css` | Интерфейс и оформление |
| Orchestration | `app.js` | Очередь файлов, Worker-потоки, фильтры, таблица, экспорт |
| Parsing | `worker.js` | Сигнатуры, чтение двоичных структур, метаданные и валидация |

## Как запускается

1. Откройте папку `lab2`.
2. Запустите локальный HTTP-сервер в этой папке (например, `python -m http.server 8000`).
3. Откройте `http://localhost:8000` в актуальном браузере на базе Chromium.
4. Нажмите **«Выбрать папку»** и укажите папку с тестовыми изображениями.
5. Дождитесь окончания сканирования. Используйте фильтры и экспорт CSV для анализа результата.

Выбор папок зависит от возможностей браузера и обычно лучше поддерживается в Chromium-браузерах. Для GitHub Pages загрузите содержимое папки `lab2` в соответствующий каталог репозитория и включите Pages в настройках репозитория.

## Откуда берутся значения

- **Размер:** поля заголовка или теги ширины и высоты.
- **Разрешение:** JFIF для JPEG, `pHYs` для PNG, pixels-per-meter для BMP, X/YResolution и ResolutionUnit для TIFF, DPI-поля PCX. Если оно не задано в самом файле, приложение не подставляет фиктивное значение.
- **Глубина цвета:** bits-per-pixel, bit depth либо `BitsPerSample` и число каналов — в зависимости от формата.
- **Сжатие:** поле или тег формата; для некоторых форматов выводится используемый стандартом метод.
