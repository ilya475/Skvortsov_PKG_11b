**Студент:** Скворцов Илья  
**Тема:** Чтение информации из графических файлов

## Запуск
Откройте `index.html` в современном браузере через локальный HTTP-сервер либо разместите четыре основных файла (`index.html`, `style.css`, `app.js`, `worker.js`) в корне GitHub-репозитория и включите GitHub Pages. Для корректной работы Web Workers предпочтителен HTTP(S), а не открытие файла двойным щелчком.

## Возможности
- анализ JPEG/JPG, GIF, TIFF/TIF, BMP, PNG и PCX;
- ручное чтение бинарных полей без сторонних библиотек метаданных;
- определение формата по сигнатуре, а не по расширению;
- выбор папки или отдельных файлов;
- параллельный разбор в Web Workers;
- чтение только необходимых диапазонов через `Blob.slice()`;
- проверка обязательных структур и границ файла;
- поиск, фильтры, постраничный вывод по 100 строк;
- экспорт результатов в CSV и просмотр изображения.

## Архитектура
- `index.html`, `style.css` — интерфейс;
- `app.js` — очередь, пул рабочих потоков, прогресс, фильтры и экспорт;
- `worker.js` — ручные парсеры форматов.

## Расчёт DPI при отсутствии метаданных
Сначала приложение пытается извлечь физическое разрешение из полей формата (JFIF/EXIF, pHYs, X/Y pixels per meter, HDPI/VDPI или TIFF-теги). Если эти данные отсутствуют, программа показывает условную оценку **≈96 × 96 dpi** и помечает её как условную. Это принятое расчётное допущение, а не значение, прочитанное из файла. Точное физическое DPI нельзя однозначно получить только из ширины и высоты в пикселях: для этого нужен ещё физический размер изображения. При наличии физического размера расчёт выполняется по формуле `DPI = размер в пикселях / размер в дюймах` (для сантиметров: `DPI = px × 2,54 / см`).

## Проверки
В каталоге `tests/` приложены исходные тестовые наборы, использованные при локальной проверке парсеров. Сводка и ограничения испытаний описаны в отчёте `Отчет_Скворцов_Илья_Лаб2.docx`. Нагрузочный тест набора примерно из 600 JPEG общим объёмом около 2 ГБ нужно выполнить на целевом компьютере: время зависит от накопителя, браузера и оборудования.
