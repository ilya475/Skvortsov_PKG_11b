# План проверки

1. Распаковать `tests/Для проверки Lab2.zip` и выбрать папку в приложении. Ожидается корректное чтение 24 BMP.
2. Распаковать `tests/Lab2_parser_test_files.zip`. Проверить 4 корректных файла (JPEG, PNG и два TIFF) и 4 отрицательных случая (JPEG без EOI, PNG без IEND, усечённый TIFF, текстовый файл с расширением JPG).
3. Дополнительно подготовить GIF и PCX, поскольку в предоставленных архивах нет контрольных файлов этих форматов.
4. Для проверки производительности выбрать набор около 600 JPEG суммарным объёмом около 2 ГБ. Зафиксировать число файлов, суммарный размер, длительность и количество ошибок. Не переносить в отчёт время, полученное на другом компьютере.
5. Проверить интерфейс во время обработки: прокрутку, поиск, фильтры, переключение страниц и экспорт CSV.

6. Для файлов без DPI-полей проверить, что в столбце разрешения отображается «≈96 × 96 dpi (условно)», а в деталях явно указано, что значение принято условно, а не считано из файла.
