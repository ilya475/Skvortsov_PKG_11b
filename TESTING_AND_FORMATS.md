# Проверка лабораторной работы № 2

## Перед запуском

- [ ] Открыть приложение через локальный HTTP-сервер в актуальном Chromium-браузере.
- [ ] Убедиться, что Worker-файл загружается без ошибок в консоли.
- [ ] Проверить выбор папки, очистку результатов и повторный запуск сканирования.

## Обязательные форматы

Для каждого формата JPEG/JPG, GIF, TIFF/TIF, BMP, PNG и PCX проверить не менее одного корректного файла:

- [ ] Формат определён по содержимому.
- [ ] Ширина и высота совпадают с эталонными данными.
- [ ] Глубина цвета и сжатие соответствуют заголовку/тегам.
- [ ] Разрешение выводится, только если оно записано в файле.
- [ ] Отсутствующие поля обозначаются явно, а не заполняются вымышленными значениями.

## Повреждённые и подменённые файлы

- [ ] JPEG без завершающего EOI (`FF D9`) получает статус повреждённого.
- [ ] PNG без IEND получает статус повреждённого.
- [ ] Файл с текстовым содержимым и расширением `.jpg` не распознаётся как корректный JPEG.
- [ ] Короткий/обрезанный файл не приводит к остановке всего сканирования.
- [ ] После ошибки одного файла остальные задания продолжают обрабатываться.

## Производительность и интерфейс

- [ ] Набор «Для проверки Lab2» обработан, результаты сверены с эталонными.
- [ ] Дополнительный набор `Lab2_parser_test_files.zip` обработан, ошибки сверены с ожидаемыми.
- [ ] `Test_10000.zip` проверен для большого числа файлов.
- [ ] Если доступен JPEG-набор около 2 GB, измерено время обработки и подтверждено отсутствие загрузки всех файлов целиком.
- [ ] Во время сканирования интерфейс остаётся доступным.
- [ ] Прогресс достигает 100%, а число обработанных файлов равно числу выбранных файлов.
- [ ] Поиск, фильтры, постраничная навигация и CSV-экспорт работают.
- [ ] Повторный запуск после очистки не смешивает результаты предыдущего сканирования.

## Что фиксировать в отчёте

Для каждого прогона записать: название набора, число файлов, число OK, число повреждённых, время, браузер и компьютер. Добавить скриншот таблицы результатов и прогресс-бара. Не переносить старые измерения как новые: время зависит от оборудования и условий запуска.

## Технические границы

Проверки сигнатур и обязательных маркеров помогают обнаруживать распространённые повреждения, но сами по себе не доказывают полную валидность каждого возможного варианта формата. Особенно важно отдельно проверить TIFF с разными порядками байтов и типами значений IFD, а также JPEG с необычно длинными сегментами перед SOF.
