Реализованные методы

Пошаговый

Число шагов N = max(|Δx|, |Δy|); на каждом шаге координаты округляются.

ЦДА

xᵢ₊₁ = xᵢ + Δx/N; yᵢ₊₁ = yᵢ + Δy/N. Используются приращения и округление.

Брезенхем

Ошибка e = |Δx| − |Δy| управляет выбором соседнего пикселя. Знаки приращений позволяют пройти все октанты.

Окружность

Решение принимается по целочисленной переменной d = 3 − 2r. Восемь симметричных точек строятся за один шаг.

Ву (Wu)

Два пикселя получают интенсивности 1 − f и f, где f — дробная часть координаты; это обеспечивает плавную границу.

Кастла–Питтвея

Целочисленный midpoint-подход для конического сечения (эллипса): две области и четырёхкратная симметрия.
